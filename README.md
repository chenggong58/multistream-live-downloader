# Multistream 直播下载器

一个带图形界面（GUI）的多平台直播下载器，基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 构建。

支持 **YouTube / Twitch / B站 / 抖音 / TikTok（国际版）** 的直播与视频下载。粘贴链接即可**自动识别平台**、**自动选择最高画质**，支持**多任务并发**下载，还能在下载过程中随时加入新的直播。

## ✨ 功能特性

- 🎯 **自动识别平台**：粘贴链接自动判断属于哪个平台，无需手动选择
- 🎬 **自动最高画质**：`bestvideo*+bestaudio/best`，优先分离音视频取最高画质，直播单流自动回退
- ⚡ **多任务并发**：每个链接独立线程下载，互不干扰
- ➕ **中途加播**：下载进行中随时粘贴新链接再点「开始下载」，只下载新增的，正在下的不中断
- ⏹ **停止单任务**：在任务列表点选某一行即可单独停止该任务，已下载部分保留
- 🔔 **完成提醒**：任务下载完成后自动播放系统提示音
- 🚀 **启动自检**：自动检测本机代理端口（Clash/FlClash）与 ffmpeg 是否就绪
- 🌐 **代理支持**：支持代理下载，适配 Clash / FlClash 等工具

## 📦 环境要求

- Python 3.8+
- 依赖库：`yt-dlp`
- [ffmpeg](https://ffmpeg.org/)（用于音视频合并，需加入系统 PATH）

安装依赖：

```bash
pip install yt-dlp
```

## 🚀 使用方法

1. 运行脚本：`python 直播下载器.py`
2. 在输入框粘贴直播/视频链接（可多行，每行一个）
3. 选择保存文件夹
4. 点击「开始下载」

下载 YouTube / Twitch 等平台时建议开启代理；下载抖音 / TikTok 遇到风控时可更换节点。

### 中途加播

下载过程中，把新的直播链接粘进输入框，再点一次「开始下载」即可，正在下载的任务完全不受影响。
